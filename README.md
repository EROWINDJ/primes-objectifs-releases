# Primes & Objectifs — téléchargements

Ce dépôt est réservé aux APK release signés, à leurs empreintes SHA-256, aux métadonnées de mise à jour et aux notes de version.

**Le brouillon 0.1.21 est obsolète : ne pas installer ni publier son APK.** Le correctif 0.1.22 est compilé et reste en attente de recette avant toute diffusion stable.

Aucune version stable n’est publiée pour le moment. Les candidats restent en brouillon jusqu’à validation explicite.

Le code source et les données des utilisateurs ne sont pas hébergés ici.
