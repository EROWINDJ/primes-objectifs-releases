**Nouveauté 0.1.25 :** pour une vente sans installation nécessaire, 100 % de la commission finale est prévu selon le calendrier signature. Les ventes qui nécessitent une installation conservent la répartition 50/50. Le choix est conservé dans les sauvegardes ; les anciennes ventes restent en mode « installation nécessaire ».

Depuis une release précédente de salesView, ouvrez l’application pour laisser la vérification automatique proposer la nouvelle version, ou utilisez **Paramètres → À propos → Vérifier les mises à jour**. Une réponse réseau réussie peut rester en cache jusqu’à six heures pour le contrôle automatique. Le navigateur télécharge l’APK ; Android confirme son installation par-dessus l’application existante. Le certificat release et l’identifiant Android restent identiques.

Les installations debug utilisent un autre certificat : vérifiez une sauvegarde avant toute transition vers une release. Le code source et les données des utilisateurs ne sont pas hébergés dans ce dépôt public.
